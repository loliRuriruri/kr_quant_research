              ℹ️
              
                  계절성 상태(Status) 분류 가이드
                  
            
                  
            
                  과거 반복 통계 + 현재 연결된 퀀트·모멘텀·수급 근거 판정 체계
                  
          
                  
          
        
                  

        
        
                  
          💡 상태(Status)는 어떻게 판정되나요?
          ①월간 반복 수익률·승률, ②설명 가능한 이벤트 가설, ③실제로 연결된 최신 퀀트·3개월 모멘텀·기관/외인 수급만 사용합니다. 벤치마크·거래량 등 미연결 자료는 점수에서 제외합니다.
        
                  

        
        
                  
          
                  
            🟢 ACTIVE (현재 근거 확인)
          
                  
          
                  
            과거 반복 패턴에 더해 현재 연결된 퀀트·모멘텀 근거가 기준을 통과한 우선 관찰 후보입니다. 주문 신호는 아닙니다.
          
                  
          
                  
            
                  • 판정 조건: 계절성 점수 78점 이상 + 과거 승률 70% 이상 + 최근 3개월 수익률 양호
                  
            
                  • 확인 가이드: 실측 피크 경로·거래 가능성·누락 근거를 종목 상세에서 재확인
                  
          
                  
        
                  

        
        
                  
          
                  
            🟡 WATCH (관찰 / 대기)
          
                  
          
                  
            과거 계절성 패턴은 우수하나, 올해 수급 유입이나 이벤트 촉매 발생을 확인 대기 중인 상태입니다.
          
                  
          
                  
            
                  • 판정 조건: 계절성 점수 68점 이상 또는 최근 3개년 승률 60% 이상
                  
            
                  • 확인 가이드: 거래량과 외인·기관 수급이 실제로 연결될 때까지 관찰
                  
          
                  
        
                  

        
        
                  
          
                  
            🟣 DISCOVERY (신규 발굴)
          
                  
          
                  
            최근 3~5년간 새롭게 계절성 상승 패턴이 형성된 신규 발굴 후보주입니다.
          
                  
          
                  
            
                  • 판정 조건: 표본수 3년 이상 + 승률 67% 이상 + AI 원인 역추적 진행
                  
            
                  • 확인 가이드: 표본 확대와 이벤트·현재 데이터 근거 추가 확인
                  
          
                  
        
                  

        
        
                  
          
                  
            🟠 WEAKENING (엣지 약화)
          
                  
          
                  
            과거에는 강했으나 최근 3년간 승률이나 월간 수익률이 하락하여 계절성 모멘텀이 둔화된 상태입니다.
          
                  
          
                  
            
                  • 판정 조건: 최근 3개년 승률 50% 미만
                  
            
                  • 확인 가이드: 최근 실패 연도와 무효화 조건을 우선 검토
                  
          
                  
        
                  

        
        
                  
          
                  
            🔴 BROKEN (진입 금지 / 파기)
          
                  
          
                  
            최근 3개월간 급락했거나 올해 펀더멘털 악화/실적 쇼크로 계절성 룰이 깨진 종목입니다.
          
                  
          
                  
            
                  • 판정 조건: 3개월 수익률 -15% 이하 및 퀀트 종합점수 48점 미만
                  
            
                  • 대응 가이드: 신규 매수 절대 금지 및 보유 시 즉시 리스크 관리(손절)
