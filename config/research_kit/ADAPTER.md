# KR Quant Screener 적용 규칙

이 리포트는 자동매매 신호가 아니다. 사용자가 만든 VER4.0.0 지침을 따라 **읽을 수 있는 분석리포트**를 쓴다.

## 이 실행에서 있는 것
- 읽기 전용 Quant 스냅샷(점수·PER·PBR·ROIC·성장률 등)
- 종목 마스터(이름, 시장, 업종)
- 사용자가 열 수 있는 외부 링크(네이버, DART 등)
- 네이버 검색 API 뉴스가 있으면 `naver_news`로 제공됨

## 이 실행에서 없는 것
- 네이버 키가 없을 때의 실시간 뉴스/공시 원문 검색
- 컨센서스 피드
- 장중호가, 분봉, RSI/MACD/거래량 시계열
- 과거 유사국면 자동 매칭 엔진

없는 항목은 숫자를 지어내지 말고 `확인불가(데이터 없음)`으로 쓰고, 무엇을 보면 확인 가능한지만 적는다.

## Quant 숫자
Quant 스냅샷의 PER·ROIC·점수·랭크는 이미 계산된 값이다. 덮어쓰지 마라. 재계산이 필요하면 별도 문장으로 `추정`이라고 표시하고 근거를 적는다. 출력에 `quant_score`, `quant_rank`, `quant_score_raw` 키를 만들지 마라.

## 출력
한국어 마크다운만 출력한다. JSON이나 내부 체크코드, Audit Stamp를 보이지 마라.
필수 큰 제목:
1. 45초 총평
2. 최신 뉴스·공시·이벤트
3. 재무·최근 실적·이익의 질
4. 밸류에이션
5. 성장성·경제적 해자·업계
6. 정책·테마·거시
7. 기술적 위치·거래량·수급·유사국면
8. 핵심 리스크
9. 목표가·Price & Action Map
10. 사용자별 전략
11. Final Action Playbook

마지막에 한 줄 면책: 리서치 의견이며 매수·매도 지시가 아니다.
