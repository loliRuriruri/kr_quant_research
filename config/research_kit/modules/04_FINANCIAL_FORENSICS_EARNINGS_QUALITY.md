## 1. Layered Latest Financial

최신 자료를 한 기간으로 억지 통일하지 않는다.

- 최신 잠정실적·실적발표: Revenue·OP·NI 등 최신 P&L 이벤트
- 마지막 제출 분기·반기·연간 보고서: BS·CF·주석
- 장기 확정 재무: 5~10년
- 최근 추세: 가능한 최대 8개 단독 분기

당일 2Q 잠정실적이 있고 반기보고서가 없으면 2Q를 무시하지 않는다. 2Q P&L과 직전 제출 BS·CF를 기간 구분해 병행한다.

## 6. Earnings Quality Anomaly Scan

자동 확인:

- Revenue와 OP 성장의 괴리
- Gross margin과 OPM의 괴리
- 매출 미달 + OP 대폭 상회
- 환급·보조금·자산매각·충당금 환입
- 세율·NCI·외환·금융손익
- 판관비·광고·A/S·대손·R&D·SBC 타이밍
- 전년 선주문·pull-forward·기저효과
- M&A·PPA·연결범위 변경
- 재고·채권·계약자산·선수금 급변

헤드라인 Beat를 정상 이익으로 즉시 연율화하지 않는다.

## 7. Stage A Normalization

`Reported OP → 일회성·Cycle·환율·비용타이밍 조정 → Normalized OP → Pretax → Tax/NCI → NI → diluted EPS → CFO/정상 CapEx → Normalized FCF`

정확한 일회성 금액이 공개되지 않았으면:

1. 회사 설명·Gross margin·SG&A·전년·Peer로 범위를 만든다.
2. Low/Base/High 조정을 사용한다.
3. 각 범위의 EPS·FCF·가치를 계산한다.
4. 목표가·전략의 정밀도를 낮추되 분석을 멈추지 않는다.

## 8. Stage B

`KPI·물량·가격 → 사업부 매출 → 마진·OP → 연결 OP → Pretax → Tax/NCI → EPS → CFO/FCF → 가치`

최소 Base와 Bear의 핵심 산식을 보인다.

- ROIC와 투하자본 정의

- SBC·증자·부채상환
- 성장투자가 FCF와 순차입 개선으로 이어지는지

- 가능한 최대 5~10년 수평/공통형 추세
- 최근 최대 8개 단독분기
- Gross/OP/Net/FCF margin
- CFO/NI, FCF/NI, CapEx/CFO
- 재고·채권·운전자본
- 순현금/순차입·이자비용
