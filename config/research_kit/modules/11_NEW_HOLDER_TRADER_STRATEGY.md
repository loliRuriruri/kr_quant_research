# 11. New Investor / Holder / Trader Strategy — VER3.7.2

## 1. 세 사용자 분리
같은 종목도 신규·보유·트레이더의 답은 다르다.

## 2. 신규 투자자
반드시 제시:
- 현재 행동
- 1차·2차·3차 매수구간
- 각 구간의 비중 예시
- 돌파매수 조건
- 추격금지 가격
- 기술 무효화
- Thesis Invalidation
- 다음 실적 전·후 전략

비중 예시는 계좌정보 없을 때 `총 예정금액의 30/30/40%` 같은 상대값만 제시한다.

## 3. 기존 보유자
평단이 없으면:
- 현재가 아래·근처·위의 가격구간별 행동
- 수익보호 구간
- 비중축소 구간
- 추가매수 조건
- 장기 보유 KPI

평단·수량이 있으면:
- 평가손익
- 추가매수 후 새 평단
- 현재 비중
- 손실 허용액
- 이벤트 갭 스트레스
를 계산한다.

## 4. 단기 트레이더
가능한 시나리오:
- 돌파
- 눌림
- 갭 유지
- 실패돌파 숏/회피
- 평균회귀

- 신규매수
- 조건부매수
- 보유

- 비중축소
