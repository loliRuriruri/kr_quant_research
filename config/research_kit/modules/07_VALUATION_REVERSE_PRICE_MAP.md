# 07. Valuation / Reverse / Price Map — VER3.7.2

## 1. 분모 정렬
TTM, FY1, FY2, 정상화 EPS·FCF를 구분한다. 순현금·부채·리스·희석 기준을 통일한다.

## 3. Reverse Valuation
최소 하나:
- 요구 EPS = 현재가 / 정당 PER
- 요구 OPM = 목표 OP / 매출
- 요구 FCF = 시총 × 요구 FCF yield
- 요구 성장률·점유율·수주
- SOTP에서 옵션사업에 부여된 가치

현재 가격이 무엇을 이미 믿고 있는지 평문으로 번역한다.

## 4. Stage B Scenario
`사업부 KPI → 매출 → 마진 → OP → Pretax → Tax/NCI → diluted EPS → FCF → 가치`

최소 Base와 Bear의 핵심 산식을 보인다.
| 시나리오 | 확률 | 사업 가정 | EPS/FCF | 배수 | 가치 | 촉매 | 폐기조건 |
|---|---:|---|---:|---:|---:|---|---|

## 5. Required Return
기간을 명시하고:
`Buy Ceiling = Future Value / (1+r)^t`

10%, 12%, 15%를 기본 비교한다.

## 6. Fundamental R/R
`Base upside / Bear downside`
가정이 약하면 범위로 제시한다.

## 8. 가격이 최신이 아닐 때
마지막 검증가격을 명시하고:
- 절대 가격범위
- 현재가 대비 퍼센트
- 돌파/이탈 조건
을 함께 적는다. 분석을 통째로 생략하지 않는다.

## VER3.7.2 Valuation Minimum Pack
- TTM/FY1/FY2/Normalized를 분리한다.
- Reverse Valuation + Bear/Base/Bull을 기본 수행한다.
- 10%·12%·15% 요구수익률 매수상한을 모두 제시한다.
- Fundamental R/R 1.5x·2.0x가 허용하는 매수상한을 가능한 범위에서 계산한다.
- 목표가, 가치가격, 실제 진입가격을 분리한다.
12% 상한 하나만 제시하면 Quality Gate 실패다.
