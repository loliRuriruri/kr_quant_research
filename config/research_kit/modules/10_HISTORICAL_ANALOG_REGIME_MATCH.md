# 10. Historical Analog & Regime Match — VER3.7.2

## 1. 목적
사용자가 따로 말하지 않아도 **“과거에도 비슷한 장면이 있었는가?”**를 자동 점검한다.

## 2. Same-stock Analogs
우선 같은 종목에서 찾는다.
- 실적 Beat 후 하락
- 발표 전 급등 후 Sell-the-News
- 저항 돌파 실패
- 200일선 회복·이탈
- 대량거래 갭
- 계절적 성수기·비수기
- 밸류 저점·고점
- 업종 강세인데 종목 약세

## 3. Matching Features
비슷함을 다음 변수로 평가한다.
- 이벤트 유형
- D-20/D-60 수익률
- 시장·업종 RS
- 가격 vs 20/50/200일선
- RSI·ATR
- 거래량 배수
- 실적 Surprise
- FY1/FY2 Revision
- 계절 분기
- 밸류에이션
- 산업 Cycle

## 4. 최소 표본
최소 2개, 가능하면 3~5개.
| 과거 날짜 | 당시 셋업 | 공통점 | 차이점 | D+5 | D+20 | D+60 | 현재 의미 |
|---|---|---|---|---:|---:|---:|---|

동일 종목 표본이 부족하면:
1. 같은 업종 Peer
2. 같은 이벤트 구조
3. 같은 시장 국면
순으로 보조한다.

## 5. 해석
- 반복성 있음
- 혼재
- 구조변화로 비교 제한
- 근거부족

과거 결과를 미래 확률로 그대로 쓰지 않는다. 현재와 다른 사업구조·유동성·시장국면을 반드시 적는다.

## 6. Strategy Link
- 과거에도 저항 실패 반복 → 돌파 확인 강화
- 과거 Sell-on 후 D+20 회복 → 분할·확인 매수 후보
- 리비전 하락 동반 반복 → 가치모델 재검증
- 대량거래 갭 반납 반복 → 추격금지·무효화 강화

## VER3.7.2 Analog Hard Gate
Event Trigger가 켜진 종목은 같은 종목 과거 유사국면 최소 2개, 가능하면 3~5개를 찾는다.
각 사례는 당시 선행수익·거래량·실적/뉴스·D+1/D+5/D+20/D+60 경로와 현재와의 차이를 비교한다.
검색 후 정말 사례가 부족할 때만 `동일종목 analog 부족`을 명시하고 업종/peer 사례를 보조로 사용한다.
