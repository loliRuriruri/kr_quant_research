# 08. Multi-Timeframe Technical / Intraday / Trend / Pattern — VER4.0.0

## 1. 목적

가치평가를 바꾸는 것이 아니라 **언제, 어디서, 어떤 조건으로 실행할지** 결정한다. 당일 이벤트 종목은 장중 반응과 완성봉 추세를 분리한다.

## 2. Two-Layer Data

### Intraday Layer

- 현재 장중가·등락률·고가·저가
- 시초가·갭·VWAP·장중 저점 회복
- 현재 거래량과 20일 평균·동시간대 pace
- 가능한 외국인·기관·프로그램 수급

### Completed-Bar Layer

- 전일 완성 일봉
- 완성 주봉·월봉
- 이동평균·RSI·MACD·ADX·ATR·RS

미완성 당일봉은 확정 신호가 아니지만 최신 가격반응을 분석하는 자료다. 이를 이유로 기술분석·가격대를 생략하지 않는다.

## 3. Timeframes

### 장기 — 월봉·주봉

- 2~5년 고저점
- 40주·200일선 위치와 기울기
- 52주·역사적 고점 거리
- Stage 1 Base / 2 Uptrend / 3 Distribution / 4 Downtrend
- 장기 매물대·구조적 지지

### 중기 — 주봉·일봉

- 20/50/60/120일선 배열·기울기
- HH/HL 또는 LH/LL
- 베이스·돌파·리테스트
- 3~6개월 RS
- 주요 갭·대량거래 매물대

### 단기 — 일봉·장중

- 5/10/20일선
- 최근 5~20일 캔들·갭
- ATR·변동성 수축/확대
- 당일 거래량 pace와 종가 예상 위치
- 이벤트 첫 봉·둘째 봉

## 4. Pattern Recognition

자동 점검:

- 박스권
- Double Bottom/Top
- Head & Shoulders / Inverse
- Cup & Handle
- Flag/Pennant
- Wedge/Triangle
- VCP
- Breakout / Failed Breakout
- Gap-and-Go / Gap Fill
- Support-Resistance Flip
- Climax Top / Selling Climax

가격구조·기간·거래량 조건을 충족할 때만 이름을 붙인다.

## 5. Moving Average and RS

- 5/10/20/50/60/120/200일선과 40주선
- 위치·기울기·정배열/역배열·이격
- 시장·업종 대비 20/60/120일 RS
- Down-Day RS
- 가격 횡보 중 RS 개선 여부

크로스 자체보다 가격구조·거래량을 우선한다.

## 6. Support / Resistance

겹치는 근거:

- 과거 고저점
- 갭
- 이동평균
- 대량거래 매물대
- Volume Profile·Anchored VWAP
- ATR 범위

최소 2개가 겹치면 핵심 가격대로 승격한다.

## 7. Trend Verdict

|---|---|---|---|---|---:|---:|---|
| 단기 1~4주 | | | | | | | |
| 중기 1~6개월 | | | | | | | |
| 장기 6~24개월 | | | | | | | |

단기·중기·장기가 충돌하면 신규·보유·단기 중 누구에게 유리한지 설명한다.

## 8. Execution

가능하면:

- 1차 눌림
- 2차 중기 지지
- 3차 장기 지지
- 돌파 종가·거래량·리테스트
- 추격금지
- 목표 1·2
- 기술 무효화

정확한 최신가가 부족하면 마지막 검증가격 대비 퍼센트와 조건을 병기한다. 가격지도 자체를 삭제하지 않는다.


## 9. VER4.0.0 Pattern Validation

패턴 이름은 모양만 보고 붙이지 않는다. `구조 기간 + 피벗 고저점 + 거래량 + 돌파/이탈 종가 + 실패조건`이 있어야 한다. 이벤트 당일은 갭·VWAP·저점회복·거래량 pace를 별도 해석하고, 완성봉 추세와 섞지 않는다.
