# 17. Skill Alignment / Stale Anchor Guard — VER4.0.0

## 목적

자동 호출되는 `equity-research-decision-engine` 스킬과 프로젝트 지침이 충돌해 최신 검색보다 과거 예시·내부 게이트가 우선되는 문제를 막는다.

## 우선순위

1. 시스템의 현재 날짜·사용자 현지시각
2. 현재 요청에서 검색한 최신 공식·시장자료
3. 현재 요청에 첨부된 자료
4. 프로젝트 지침과 분석 템플릿
5. 스킬의 합성 예시·과거 회귀테스트

5번은 절대로 현재 사실의 출처가 아니다.

## 스킬 호출 시 필수

- Live Retrieval을 가치·Readiness보다 먼저 수행
- 최근 24h/7d/30d 뉴스 검색
- 잠정실적과 제출보고서 역할 분리
- 장중과 완성봉 분리
- post-event revision Pending이어도 분석·가격지도 계속
- 내부 정밀도 코드는 최종 출력에서 숨김
- 프로젝트 14 출력 순서를 따름

## 금지 충돌

- 스킬 예시가 특정 종목·날짜와 비슷하다는 이유로 같은 상태를 재사용
- `T0/V1` 같은 코드로 최신 뉴스·차트·가격전략을 생략
- 프로젝트는 최신 잠정실적을 요구하는데 스킬이 이전 분기만 사용
- 스킬 Audit Stamp가 프로젝트 Final Action Playbook을 밀어냄

## Recovery

충돌이 의심되면:

1. 현재 검색 후보를 시간순으로 다시 나열
2. 가장 최신 뉴스·실적·가격을 재선택
3. 잠정 P&L + 제출 BS/CF로 재구성
4. 장중 반응 + 전일 완성봉으로 차트 재분석
5. 상단 총평과 가격지도를 갱신


## VER4.0.0 Sample-Method / Sample-Data 분리

참고 분석에서 가져올 것은 **방법**뿐이다: 결론 우선, 숫자 검산, 모순 분해, 시장반응, 판결 KPI, 서사 타임라인. 특정 종목·날짜·가격·실적·등급은 어떤 경우에도 현재 분석의 기본값으로 재사용하지 않는다.
