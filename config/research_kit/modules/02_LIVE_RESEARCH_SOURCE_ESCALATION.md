# 02. Live Research / Source Escalation / Same-Day Event — VER3.7.2 Cloud-First Deep

## 1. 목적

최신 정보 검색이 한 번 실패했거나 특정 API가 없다는 이유로 과거 데이터에 고정되는 문제를 막는다. **웹·공식자료가 기본 경로이고 Skill/connector는 가속·보강 경로**다.

## 2. Mandatory Retrieval Matrix

| 대상 | 최소 확보자료 | Cloud 1차 출처 | 보조/Skill |
|---|---|---|---|
| 최신 뉴스 | 24h/7d/30d 이벤트 | 회사·거래소·규제기관 | 주요 언론·포털 |
| 현재가격 | 최신 검증가격 + 최신 종가 | 거래소/신뢰 웹 시세 | 주요 금융포털 |
| EOD 수급 | 투자자별 완료 거래일 | KRX | 포털/증권사 |
| 장중 수급 | 가능한 경우만 | 검증 가능한 broker/provider | 없으면 미확인 |
| 공매도·대차·신용 | 최신 공개 기준일 | KRX/공식시장자료 | 포털/증권사 |
| 최신 실적 | 잠정/발표 P&L | 거래소·회사 IR | 언론·포털 |
| 제출 재무 | BS·CF·주석 | DART/SEC/EDINET | 데이터포털 |
| 컨센서스 | FY1/FY2·pre/post | 리포트/provider | 포털·언론 |
| 차트 | 1~5년 OHLCV | 거래소/KRX | data-stock/차트포털 |
| 거시 | 금리·FX·CPI·M2 | BOK/정부/Fed/BOJ | bok-ecos-stats/FRED |
| 산업·정책 | 수요·재고·가격·공식단계 | 정부·협회·Peer | 언론·리서치 |

## 3. Data Finality

- 현재/장중 검증가격
- 완료 거래일 공식/확정 데이터
- 잠정실적·회사 발표
- 제출재무
- 컨센서스 snapshot

장중 수급은 신뢰 가능한 공급자가 있을 때만 별도 층으로 추가한다.

## 4. Search Escalation Ladder

최소 3개 쿼리와 2개 출처군을 시도한다.

### 최신 이벤트
1. `회사명 + 티커 + 오늘 최신 뉴스`
2. `회사명 + 연도 + 분기 + 잠정실적`
3. `회사명 + 영업(잠정)실적 + 공정공시`
4. `회사명 + 실적발표 + 오늘 날짜`

### 공식 원문
5. 회사 IR 도메인 + 분기/날짜
6. 거래소·규제기관 도메인 + 회사명/티커
7. 공시유형·접수일·보고서명 변형

### 가격·수급
8. 최신 검증가격과 당일 거래량을 신뢰 웹 시세에서 확인
9. KRX 또는 data-stock으로 마지막 완료 거래일 OHLCV 확인
10. KRX/공식자료로 최신 EOD 외국인·기관·개인 수급 확인
11. 공매도·대차·신용 최신 공개일 확인
12. `티커 + 오늘 주가 + 거래량 + 외국인 + 기관`

### 확장
13. 영문·현지어 회사명
14. 최신 기사에서 원문 링크 역추적
15. PDF/이미지/표는 필요한 경우 직접 확인

## 5. Same-Day Event Rule

당일 잠정실적이 있고 제출 보고서가 아직 없으면:

- 잠정 매출·OP·NI를 최신 P&L로 사용
- 마지막 제출 보고서의 BS·CF·주석을 별도 사용
- 최신 검증가격·당일 거래량을 초기 반응으로 사용
- 전일 완성봉으로 이동평균·ATR·RS 계산
- post-event 리비전이 없어도 정상화·Reverse·Bear/Base/Bull·조건부 전략 수행

## 6. Current Price & Flow Rule

- 장중: 최신 검증가격·시각·등락·고저·거래량 + 전일 종가
- 장후: 최신 정규장 종가 + 시간외를 분리
- 휴장: 마지막 거래일 종가
- 2거래일 이상 오래된 가격을 현재가라고 쓰지 않음
- 장중 외인/기관/프로그램 수급이 검증되지 않으면 수치화하지 않음
- 대신 EOD 수급 3D/5D/20D, 가격·거래량·RS로 경로를 판단

## 7. External Skill Fallback

- `data-stock`이 있으면 EOD 가격/거래량/시총 확인에 사용하고 실시간으로 표현하지 않는다.
- `bok-ecos-stats`가 있으면 ECOS 시계열 확보에 사용한다.
- Skill 호출이 불가능하면 공식웹을 직접 검색한다.
- 외부 Skill의 결론은 버리고 데이터/검수 결과만 재사용할 수 있다.

## 8. Missing Data Recovery

1. 쿼리 변경
2. 공식 도메인 직접 검색
3. 다른 보조 provider 확인
4. 최신 기사에서 원문 역추적
5. 마지막 검증 데이터 + 기준일 명시
6. 범위/조건부 전략으로 정밀도 조정

단순 N/A로 분석을 끝내지 않는다.

## VER3.7.2 Filed-Report Recovery Ladder
최신 제출 보고서의 존재가 확인됐는데 BS/CF/주석을 못 읽은 경우:
1. 회사명/티커/보고서명/제출일을 바꿔 공식 검색 재시도
2. 같은 규제기관의 다른 endpoint/문서 뷰어
3. 거래소/KIND/EDGAR/EDINET 등 대체 공식 경로
4. 회사 IR/보고서 PDF
5. 보고서 직접 열기와 표/주석 확인
6. 신뢰 보조 DB
7. 그래도 실패한 경우에만 직전 제출 BS/CF + 기준일 + 영향
한 번의 실패로 직전 분기로 후퇴하면 Quality Gate 실패다.
