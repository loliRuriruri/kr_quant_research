# 02. Live Research / Source Escalation / Same-Day Event — VER4.0.0

## 1. 목적

최신 정보 검색이 한 번 실패했거나 검색 색인이 늦다는 이유로 과거 가격·실적에 고정되는 문제를 막는다.

## 3. Search Escalation Ladder

최소 3개 쿼리와 2개 출처군을 시도한다.

### 최신 이벤트

1. `회사명 + 티커 + 오늘 최신 뉴스`
2. `회사명 + 연도 + 분기 + 잠정실적`
3. `회사명 + 영업(잠정)실적 + 공정공시`
4. `회사명 + 실적발표 + 오늘 날짜`

### 공식 원문

5. 회사 IR 도메인 + 분기/날짜
6. 거래소·규제기관 도메인 + 회사명/티커
7. 공시유형·접수일·보고서명 변형

### 가격·시장반응

8. `티커 + 오늘 주가 + 거래량`
9. `회사명 + 장중 급등/급락 + 날짜`
10. 거래소·금융포털·브로커 데이터

### 확장

11. 영문·현지어 회사명
12. 최신 기사에서 원문 링크 역추적
13. 표·PDF·이미지면 렌더링 후 확인

첫 검색 결과가 오래됐으면 요약문을 최신 사실로 확정하지 않는다.

## 4. Freshness Candidate Table — 내부

| 후보 | 발표/거래시각 | 기간 | 잠정/확정 | 연결/별도 | 출처급 | 선택 | 이유 |
|---|---|---|---|---|---|---|---|

선택한 실적·가격보다 늦은 유효 후보가 있으면 내부 오류다.

## 5. Same-Day Event Rule

당일 잠정실적이 있고 제출 보고서가 아직 없으면:

- 잠정 매출·OP·NI를 최신 실적 P&L로 사용
- 마지막 제출 보고서의 BS·CF·주석을 별도 사용
- 당일 장중가격·거래량을 초기 반응으로 사용
- 전일 완성봉으로 이동평균·ATR·RS 계산
- post-event 리비전이 없어도 정상화 범위·Reverse·Bear/Base/Bull·조건부 전략 수행

금지:

- `반기보고서가 없으므로 최신 실적은 1Q`
- `당일봉 미완성이므로 기술분석과 가격대 N/A`

## 6. Current Price Rule

- 장중: 장중가·시각·등락·고저·거래량 + 전일 종가
- 장후: 최신 정규장 종가 + 시간외 분리
- 휴장: 마지막 거래일 종가
- 2거래일 이상 오래된 가격은 현재가라고 쓰지 않음
- 정확한 최신가가 없으면 마지막 검증가격 + 퍼센트·종가조건 병기

## 7. Latest Earnings Rule

`잠정실적/실적발표 → 제출 보고서 → IR/콜 → 컨센서스`

잠정실적과 제출 재무를 경쟁 자료로 보지 않고 역할을 분리한다.

- 잠정: 최신 P&L·이벤트
- 제출: BS·CF·주석·확정 범위
- 컨센서스: 시장 기대

## 8. Post-Event Revision Pending

리비전 미확인은 다음처럼 처리한다.

- 이전 컨센서스를 발표 후 기대처럼 사용하지 않음
- 초기 가격반응을 provisional로 분류
- 가치범위를 넓힘
- 리비전과 D+1/D+5를 판정변경 조건으로 둠
- 분석·가격지도 전체를 중단하지 않음

## 9. N/A 사용

내부 기록:

`미확인 항목 / 시도한 쿼리·출처군 / 결론 영향 / 대체 판단`

최종 답변에는 필요한 영향만 1~2문장으로 요약한다.

## 10. Citation

최신 가격·실적·공시·정책·산업 데이터는 문장 바로 뒤에 출처를 붙인다. 한 요약 페이지를 모든 숫자의 유일한 근거로 사용하지 않는다.
