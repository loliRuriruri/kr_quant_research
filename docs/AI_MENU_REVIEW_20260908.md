# 메뉴별 AI 역할 점검 및 개선 순서

## 결론

무료 AI 연결은 이미 넓게 구현되어 있다. 호출 횟수를 늘리기보다 입력 근거, 분석 지침,
결과 표현, 비용 경계를 먼저 개선해야 한다. 이 문서는 코드 경로 점검이며 모든 모델의 실제
응답 품질·현재 가격 정책을 인증한 보고서는 아니다. 이번 점검 중 유료 생성은 실행하지 않았다.

| 메뉴/기능 | 확인한 연결 | 적합한 개선 역할 |
|---|---|---|
| 대시보드·점수 랭킹 | Tier1 전용 브리핑 경로 | 선정 이유, 점수 변화, 강점과 취약 팩터 비교 |
| 메이저 수급·스마트 수급·빈집 | flow/trade/empty 브리핑 | 가격·외인·기관의 일치/충돌과 누락 기간 설명 |
| 매크로·업종 | market/sector 브리핑 | 구성 지표의 방향 차이, 기준일 차이 설명 |
| 시즌 캘린더 | seasonality 브리핑 + 규칙 기반 개별 설명 | 월간 과거 패턴과 올해 확인 사실 구분, 표본 부족·반례 설명 |
| 전략·백테스트 | strategy 및 개별 진단 | 수익보다 낙폭·거래 수·비용·비교구간의 한계를 함께 비교 |
| 13F | us13f 브리핑 | 신고 시점의 보유 변화 설명. 현재 매매로 해석하지 않기 |
| 은하퀀트전설 | sunzi 페르소나 브리핑 | 역할극보다 근거·결론 우선. 명령형 매매 표현 감사 필요 |
| 개별 종목 상세 | get_tier1_insights: 뉴스·공시·기술·수급 분석 | 종목별 상충 근거와 다음 확인사항. 이미 단순 코멘트 이상의 입력 구조 |
| 심층 리포트·인포그래픽 | Tier2 사용자 선택 모델 | 사용자가 요청한 종목의 상세 종합 보고서. 무분별한 메뉴 자동 생성 확대는 보류 |
| 실행 파이프라인·설정 | 운영 상태 | LLM보다 실제 상태·실패 원인·복구 버튼이 우선 |

## 발견 사항

1. `resolve_tier1_endpoint`는 OpenRouter Nemotron :free를 우선 선택하지만,
   사용할 자격 경로가 없으면 사용자 선택 제공자로 fallback한다. 따라서 UI의 '항상 무료' 전제는 부정확하다.
   유료 fallback은 명시적 선택으로 분리하고 실제 제공자/경로를 표시하는 별도 보완이 필요하다.
2. 시즌 개별 이벤트 설명은 RULE_BASED/CURATED 등 규칙·업종 가설일 수 있다.
   이를 AI가 실제 사건을 역추적했다는 제목으로 표시하면 과장이다.
3. NaN이 float 변환을 통과해 '+nan%'를 현재 근거로 세었다. 유한 수 검사와 기존 캐시 표시 방어가 필요하다.
4. 표본·피크·비용 경고를 여러 문단 반복해 핵심 수치보다 설명이 길다. 중요 경고 한 줄과 상세 접기를 분리한다.
5. 프롬프트만 개선해도 모델 응답 정확성이 보장되지는 않는다. 이후 메뉴별 실제 출력 표본 평가가 필요하다.

## 이번 첫 패치

- 공통 Tier1 JSON 브리핑에 결론/수치 근거/상충 근거/다음 확인 지침 추가. 기존 JSON 구조는 유지.
- 캐시 버전 변경으로 이전 지침 결과와 구분. 개별 종목 analyze.py 별도 프롬프트는 이번에 변경하지 않음.
- 시즌 상세의 반복 주의사항을 펼침 영역으로 이동. 중요 한 줄 한계는 유지.
- 규칙 기반 시즌 설명 제목을 '반복 패턴의 배경 가설'로 교체.
- NaN/무한대를 현재 근거에서 제외. 기존 캐시에 잘못된 문자열이 있으면 화면 판단 보류와 재계산 안내.

## 후속 우선순위

1. 무료/유료 fallback 동의 및 표시 정합성: 자동 유료 호출을 사용자에게 숨기지 않기.
2. 메뉴별 입력 근거 계약 보강: 종목·기준일·원천·결측·반례를 모델에 함께 전달.
3. 고정 표본으로 기존/새 무료 AI 결과 비교: 숫자 오류, 없는 사실, 근거 연결, 반복 문구, 지연 측정.
4. 검증된 공통 형식만 전체 메뉴에 확대. 핵심 결론 1문장 + 근거 2개 + 다음 확인 1개, 원문은 접기.
5. 유료 심층은 명시적 요청에 유지. 무료 실패가 곧 유료 호출로 이어지지 않도록 비용 정책 먼저 확정.

원천 자료 부족이나 미검증 전략을 AI 의견으로 대체하지 않는다. 이번 점검만으로
전 메뉴 AI 개선·실모델 품질 검증·공개 배포가 모두 완료됐다고 보고하지 않는다.
