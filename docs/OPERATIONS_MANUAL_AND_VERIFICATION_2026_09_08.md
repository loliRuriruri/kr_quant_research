### 2.2 매일 데이터 갱신

서버가 켜진 뒤 실행 파이프라인 → 오늘 필요한 데이터 자동 관리 → 스마트 실행 하나만 누르는 것이 기본 절차입니다.

스마트 실행은 현재 상태를 읽은 후 필요한 단계만 순서대로 실행합니다.

~~~text
KRX 기준일 확인
  → 필요할 때 KRX 일봉 갱신
  → 필요할 때 OpenDART 재무 갱신
  → 퀀트 점수·전략 캐시 재계산
  → 현재 수급 확인/갱신
  → 품질검사
  → 조건을 만족할 때만 공개 스냅샷 배포
~~~

완료 여부는 버튼을 누른 사실이 아니라 다음 항목으로 판단합니다.

- KRX 시세 기준일과 예상 기준일이 일치하는가
- 퀀트 점수 기준일이 KRX 기준일과 일치하는가
- 실행 로그에 quality success 또는 정상 완료가 기록되는가
- 수급에 expected_date, current_rows, excluded_rows, 제외 사유가 표시되는가
- 공개 배포가 blocked가 아니라 success인지 확인하는가

스마트 실행이 일부 단계만 완료하면 이전 정상 파일은 보존되고 다음 실행에서 남은 단계부터 이어집니다. 실패한 단계를 성공으로 표시하기 위해 force를 사용하지 않습니다.

### 2.3 개별 버튼을 누르는 경우

개별 작업은 장애 복구·특정 데이터만 다시 받을 때 사용합니다. 평소에 네 버튼을 모두 누를 필요가 없습니다.

| 화면 버튼 | 언제 사용하는가 | 결과와 주의 |
|---|---|---|
| 지금 즉시 일봉 시세 갱신 (krx-prices) | KRX 공식 일봉이 준비되는 18:10 이후 또는 다음 날 아침 | 약 2,700개 전 종목의 시세·마스터·당일 상태를 갱신합니다. 15:30 직후에는 공급처가 아직 준비되지 않을 수 있습니다. 시세만 바뀌고 점수는 자동으로 최신이 되지 않을 수 있으므로 상태 카드 확인 후 재계산합니다. |
| 빠른 갱신 + 전체 재계산 (live) | 주 1회, 실적 발표기, 시세와 재무를 함께 새로 계산할 때 | KRX와 DART 우선 대상(기본 시총 상위 약 400개)을 갱신하고 5대 팩터·전략을 재산출합니다. 수 분 걸릴 수 있습니다. |
| 선택 기간 시세 이력 채우기 (krx-history) | 백테스트·시즌 장기 이력이 부족할 때 최초 1회 또는 기간 확장 시 | 3/5/7/10년 중 선택한 거래일을 채웁니다. 이미 있는 날짜는 건너뜁니다. 5년은 약 1,250거래일의 기본 선택이며, 이력 확장은 역사적 PIT 검증을 자동으로 완성하지 않습니다. |
| DART 전 종목 끝까지 자동 수집 (dart-backfill) | 상위 400개 밖의 재무 커버리지를 늘릴 때 | 연속 모드는 중단 후 재개할 수 있습니다. DART 최신 공시가 곧 전 종목의 완전한 과거 재무 이력을 뜻하지는 않습니다. |

고급 메뉴의 수집 없이 기존 파일로만 재계산과 스크리닝 점수만 재계산은 원천을 받지 않고 현재 파일을 계산하는 도구입니다. 시세 기준일이 오래된 상태에서 실행하면 오래된 점수를 새 점수처럼 만들지 않으며, 화면의 기준일 경고를 반드시 확인합니다. 가상 데모 데이터 실행은 실제 투자자료를 갱신하지 않습니다.

### 2.4 자동 스케줄러

기본 설정은 config/scheduler.yaml의 다음 값입니다.

~~~yaml
enabled: true
job_kind: smart-sync
hour: 19
minute: 10
timezone: Asia/Seoul
official_flow: true
~~~

실행 파이프라인의 매일 자동 실행 스케줄러에서 다음을 확인합니다.

- 매일 자동 실행 활성화가 켜져 있는가
- 작업 종류가 스마트 일일 관리인가
- PC/서버가 19:10 KST에 켜져 있는가
- 다음 실행 예정 시각과 마지막 실행 결과가 갱신되는가

PC가 꺼져 있으면 로컬 스케줄러는 실행되지 않습니다. 자동 실행은 데이터 수집과 계산을 대신하지만, 원천 공급처가 아직 준비되지 않은 날의 자료를 만들어내지는 않습니다. 장 마감 직후 자료가 없으면 다음 예약 시도에서 재시도합니다.

## 3. 메뉴별 원천·해석 매뉴얼

### 대시보드·점수 랭킹

- 재무 Quant 점수는 가치 30, 품질 25, 성장 25, 모멘텀 10, 안정 10의 결정론적 팩터로 계산합니다.
- AI 설명, KIS/Toss 수급, 매크로, 13F, 기술적 지표는 점수를 바꾸지 않는 오버레이입니다.
- 현재 유니버스의 TOP20/TOP30은 연구용 현재 후보 요약입니다. 과거 날짜의 당시 시장 전체 모집단을 복원한 PIT 포트폴리오가 아닙니다.
- 점수 카드의 기준일, 표본·커버리지, 위험 제외 수를 함께 확인합니다.

### 전략·백테스트

- RSI, 볼린저밴드, 골든크로스, 돈치안 등 가격 규칙을 KRX 저장 일봉으로 비교합니다.
- 학습·검증·최종검증 구간을 분리하고, 설정된 비용·매도세·슬리피지와 일봉 체결 제한을 표시합니다.
- 실시간 호가·잔량을 재현하는 시스템이 아니며, 결과는 주문 추천이 아닙니다.
- 현재 TOP20을 과거로 소급한 결과와 당시 전체 시장을 PIT 방식으로 구성한 결과를 혼동하지 않습니다.

### 스마트 수급·타점 / 메이저 수급

- Toss 수급은 외국인·기관·개인·사모 등의 일별 원천을 사용하고, KRX 일봉 기술지표를 별도로 결합합니다.
- 공식 KIS 수급은 교차검증·보조 자료이며 현재 2026-09-07 기준 확인된 46개(저장 102개)만 현재 신호에 사용할 수 있습니다.
- Toss 최신 재수집 결과는 160개 원천 중 현재 적격 141개, 제외 19개입니다. 제외는 오류가 아니라 날짜·거래상태·기간 검증을 통과하지 못한 후보를 숨기는 안전 동작입니다.
- 날짜가 맞지 않거나 ACTIVE가 아니거나 종가·거래량이 양수가 아니면 후보로 표시하지 않습니다.
- 외국인·기관 필수값이 누락·무한대·불확정이면 전체 해당 시계열을 제외합니다. 수량을 원화 금액으로 바꾸거나 누락을 0으로 채우지 않습니다.
- 호버에는 최근 5거래일의 날짜별 종가와 투자자별 수급, 설정기간 합계가 표시됩니다. 스크롤로 호버가 사라지던 문제는 수정했습니다.

### 계절성·캘린더

- KRX 일봉의 월별 반복 패턴과 이벤트 프리셋을 사용합니다. 공개 스냅샷에는 12개월 통계가 포함됩니다.
- 겨울 난방, 여름 폭염, 갤럭시/언팩, 배당, 광군제/블프 등 특수 이벤트 프리셋은 일반 월 필터와 별도의 이벤트 종목군으로 처리합니다.
- 승률 100%는 표본이 적어도 나올 수 있습니다. Wilson 95% 구간, 이항 기준 참고값, 다중 조합 보정은 해석 보조이며 Quant 점수에 합산하지 않습니다.
- 오늘의 선취매는 현재 기준일의 거래 가능성·가격·수급 게이트를 적용한 연구용 후보입니다. 카드의 진입 기간은 이벤트 기준 창이며 “오늘 주문”을 뜻하지 않습니다.
- 종목 상세의 기대 P50/P90·피크 예상은 과거 표본의 분포입니다. 미래 수익률이나 목표가를 보장하지 않습니다.

### 글로벌 매크로·시장 국면

- VIX, 금리, 국채, 환율 등 원천별 매크로 행을 오버레이로 표시합니다.
- 시장 국면 점수는 구성요소·기준일·누락 여부를 같이 확인해야 합니다. 모든 시장 상황을 하나의 확정 신호로 압축한 것이 아니며 Quant 점수에 자동 합산하지 않습니다.
- 원천이 지연되면 중립이라는 라벨만으로 정상 최신 상태라고 해석하지 않습니다.

### 업종·테마·소유권 메뉴

- 업종/테마 스크리너는 현재 Quant 후보와 별도 조건으로 탐색합니다.
- OpenDART 5% 이상 대량보유는 공시 이벤트이고, KIS/Toss 일별 수급의 연기금·기금 숫자와 같은 자료가 아닙니다.
- SEC 13F는 공개된 미국 기관 보유 보고서의 지연 데이터입니다. 국내 당일 수급으로 취급하지 않습니다.
- AI 리포트는 원천과 계산 결과를 설명하는 역할만 하며 종목 점수·순위·거래상태를 변경할 수 없습니다.

## 4. 데이터 신뢰성 계약

다음 규칙은 메뉴가 달라도 공통으로 적용되는 안전장치입니다.

1. 기준일 일치: 예상 종가일보다 이전 자료만 현재 신호에 사용하고, 미래 날짜 자료는 거절합니다.
2. 거래 가능성: 해당 기준일의 ACTIVE, 양수 종가, 양수 거래량, 위험분류 통과를 요구합니다.
3. 완전성: 외인·기관 등 필수 원천 필드가 누락되면 0으로 표시해 통과시키지 않습니다.
4. 수치 유효성: NaN, 무한대, 불리언, 중복 일자·종목을 거절합니다.
5. 단위 분리: 공식 수급 금액(KRW)과 수량(shares)을 섞어 합산하지 않습니다.
6. 원천 보존: 검증 실패 후보를 원천 파일에서 지우지 않고, 화면의 현재 후보에서만 제외합니다.
7. 미확정 차단: is_final=false 자료는 현재 신호·통계에 쓰지 않습니다.
8. 캐시 무효화: 기준일·원천 해시·거래상태·코드가 바뀌면 기존 결과를 그대로 재사용하지 않습니다.
9. 원자적 저장: 새 parquet/JSON 저장 중 오류가 나도 이전 정상 파일을 파괴하지 않습니다.
10. AI 비개입: AI는 설명만 만들고 점수, 순위, 후보 게이트를 계산하지 않습니다.

## 7. 장애 대응

### 서버가 시작되지 않음

1. Stop-KR-Quant.bat을 한 번 실행합니다.
2. Get-NetTCPConnection -LocalPort 8790 -State Listen으로 점유 프로세스를 확인합니다.
3. 프로세스 경로가 KR Quant인지 확인합니다. 다른 프로그램이면 임의 종료하지 않습니다.
4. logs/web.stderr.log에서 실제 예외를 확인합니다.
5. Start-KR-Quant.bat을 다시 실행합니다.

PowerShell에서 한글이 깨지면 배치 파일의 chcp 65001, Python UTF-8 설정이 적용되는지 확인하고 Windows Terminal/UTF-8 콘솔에서 실행합니다. PYTHONIOENCODING=utf-8, PYTHONUTF8=1을 유지하며, 파일을 ANSI로 재저장하지 않습니다. 한글 깨짐은 보통 원천 데이터 손상보다 콘솔 코드 페이지가 CP949로 남아 UTF-8 출력을 잘못 해석한 경우입니다.

### 데이터가 2~3일 늦음

- KRX 공식 일봉은 장 마감 직후 공급처 준비 시각 차이가 있을 수 있습니다. 실행 파이프라인의 예상 기준일과 KRX 시세 기준일을 비교합니다.
- OpenDART는 공시 발생일·재무 적재일이 가격 기준일과 다를 수 있습니다. 공시가 늦다고 가격을 과거 값으로 맞추지 않습니다.
- KIS/Toss 수급은 공급처별 대상·확정 시각이 달라 현재 적격 행만 표시합니다.
- 날짜를 임의로 앞으로 바꾸거나, 누락을 0으로 채우거나, 화면의 중립 라벨을 최신 정상으로 간주하지 않습니다.

### 배포가 차단됨

PUBLICATION_BLOCKED는 안전장치가 고장난 것이 아니라 다음 중 하나가 현재 충족되지 않았다는 뜻입니다.

- 원천 모드가 live가 아님
- 품질 상태가 success가 아님
- 경고가 남아 있음
- 시세 기준일이 예상 기준일보다 오래됨
- 공개판과 로컬 기준일이 다름

logs/public_publish.json과 실행 파이프라인 품질 결과를 확인한 뒤 필요한 데이터 수집·재계산을 먼저 합니다. 안전장치를 끄거나 force로 공개하면 최신처럼 보이는 오래된 자료를 배포할 수 있으므로 금지합니다.

### 외부 공개판이 이전 화면으로 보임

- 공개 사이트에서 Ctrl+F5를 누릅니다.
- 운영 별칭과 배포별 주소의 build.json에서 git_commit, data_as_of, bundle_sha256을 비교합니다.
- 공개판은 로컬 PC가 꺼져도 보이지만 실시간 API를 호출하지 않습니다. 로컬에서 새로 수집·계산한 뒤 별도 배포해야 합니다.
