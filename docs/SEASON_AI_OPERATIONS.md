# 시즌 AI 운영 안내

## 적용 범위

2026-09-08 사용자 승인에 따라 시즌 상단 후보 분석에만 Grok 대체 경로를 사용한다.
다른 메뉴는 기존 무료 경로 유지. 검증하지 않은 메뉴에 유료 호출을 일괄 확대하지 않는다.
AI는 원본 점수·순위·가격을 수정하지 않는다. Top3가 있으면 AI 입력을 그 후보에 집중시키며 월별/이벤트 원본 표는 그대로 유지한다.

## 동작 순서

1. 동일 모델·프롬프트·근거 스냅샷의 정상 캐시를 먼저 읽는다.
2. 캐시가 없으면 무료 AI를 요청한다(HTTP12초, 응답 대기20초 상한).
3. 실패 시 승인된 Grok을 요청한다(HTTP105초, 응답 대기115초 상한).
4. 같은 데이터는 재사용한다. 실패 응답은 정상 분석 캐시에 저장하지 않는다.

`config/season_ai.json`의 `grok_fallback_enabled`를 false로 바꾸면 대체 호출이 중지된다.
하루(KST) 최대6회 대체 시도, 실패도 횟수에 포함. 설정으로 낮출 수 있다. 실패 후 최소5분 대기.
횟수는 `data/cache/tier1_briefings/season-budget.json`에 저장된다. 이를 삭제하면 상한 이력이 없어지므로 수동 삭제하지 않는다.
OS 파일 잠금으로 프로세스 간 중복 생성/예약을 방지한다. 기록 손상 시 유료 호출을 중지한다.
응답 대기 상한이 상위 공급자의 원격 작업 취소를 보장하지는 않는다. 지연 호출의 daemon 스레드가 잠시 남을 수 있다.

## 화면과 인증

- 작은 AI 배지는 실제 생성 플래그가 있는 해석에만 표시한다.
- Grok 결과는 '승인된 Grok 분석'과 실제 모델로 표시하며 무료라고 표시하지 않는다.
- 처음8초 이후 지연 안내를 표시한다. 아래 원본 표와 상세 수치는 계속 사용할 수 있다.
- 인증 오류 시 `grok models`로 CLI 로그인 상태를 확인한다. 필요하면 사용자가 `grok login`을 실행한다.
- API 키·AUTH 토큰은 공개 파일이나 로그에 복사하지 않는다. 구독 한도와 실제 요금은 별도 확인이 필요하다.

## 배포

Grok 호출은 로컬 Python 서버에서만 실행한다. 공개 Pages에는 인증정보/수집 엔진을 올리지 않는다.
시세 지연·기준일 불일치가 있으면 새로운 데이터 배포는 차단하고 웹 코드만 기존 데이터 유지 방식으로 배포한다.
웹 코드만 배포한 공개 화면에는 새 로컬 AI 분석이 자동으로 전달되지 않는다. 데이터 검사를 통과한 스냅샷 갱신이 별도로 필요하다.
