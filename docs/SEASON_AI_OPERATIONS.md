# 메뉴 브리핑 AI 운영 안내

## 적용 범위

메뉴 상단 브리핑은 상단 AI 칩과 별개다. 일상 경로는 NVIDIA Nemotron `:free`를 먼저 쓰고, 멈추거나 실패하면 OpenRouter `deepseek/deepseek-v4-flash-0731`이 이어 받는다. 분석이 필요할 때만 `grok-4.6` 다음 OpenRouter `deepseek/deepseek-v4-pro-0813`을 쓴다. AI는 원본 점수·순위·가격을 수정하지 않는다.

종목 클릭 해설은 무료 경로 실패 시 Flash만 이어 받고, Grok/Pro 분석 한도는 쓰지 않는다. 상단 칩에서 고른 모델은 심층 리포트 버튼에만 적용된다.

## 동작 순서

1. 동일 모델·프롬프트·근거 스냅샷의 정상 캐시를 먼저 읽는다. 해시가 바뀌어도 같은 날·같은 메뉴·같은 프롬프트의 GENERATED 해설은 재사용한다.
2. 캐시가 없으면 Nemotron `:free`를 요청한다(HTTP 8초, 응답 대기 12초).
3. 실패하면 OpenRouter Flash를 요청한다(HTTP 20초, 응답 대기 28초). Flash는 분석 한도에 포함하지 않는다.
4. 분석 한도가 남아 있으면 Grok 4.6(HTTP 105초, 대기 115초) 다음 DeepSeek Pro(HTTP 90초, 대기 100초)를 요청한다.
5. 한도·쿨다운·생성 중이거나 모두 실패해도 같은 날 직전 GENERATED 해설이 있으면 그걸 보여 빈 화면을 피한다. 실패 응답은 정상 분석 캐시에 저장하지 않는다.

`config/season_ai.json`에서 `routine_paid_enabled`를 false로 두면 Flash를 쓰지 않고, `grok_fallback_enabled`를 false로 두면 Grok을 쓰지 않으며, `analysis_pro_enabled`를 false로 두면 Pro를 쓰지 않는다.

분석 경로는 하루(KST) 최대 24회, 실패도 횟수에 포함. 실패 후 최소 90초 대기. 일상 경로(Nemotron·Flash)는 이 한도와 무관하게 계속 시도한다. 횟수는 `data/cache/tier1_briefings/season-budget.json`에 저장된다. 이를 삭제하면 상한 이력이 없어지므로 수동 삭제하지 않는다.
OS 파일 잠금으로 프로세스 간 중복 생성/예약을 방지한다. 잠금 중이면 직전 해설을 유지한다. 기록 손상 시 분석 호출을 중지한다.
응답 대기 상한이 상위 공급자의 원격 작업 취소를 보장하지는 않는다. 지연 호출의 daemon 스레드가 잠시 남을 수 있다.

## 화면과 인증

- 작은 AI 배지는 실제 생성 플래그가 있는 해석에만 표시한다. 무료·Flash·Grok·Pro를 구분해 붙인다.
- 설정 카드와 메뉴 배지는 실제 모델명을 쓰고, 유료 결과를 무료라고 표시하지 않는다.
- 처음 8초 이후 지연 안내를 표시한다. 아래 원본 표와 상세 수치는 계속 사용할 수 있다.
- 인증 오류 시 `grok models`로 CLI 로그인 상태를 확인한다. 필요하면 사용자가 `grok login`을 실행한다. Flash/Pro는 OpenRouter 키가 필요하다.
- API 키·AUTH 토큰은 공개 파일이나 로그에 복사하지 않는다. 구독 한도와 실제 요금은 별도 확인이 필요하다.

## 배포

Grok·OpenRouter 호출은 로컬 Python 서버에서만 실행한다. 공개 Pages에는 인증정보/수집 엔진을 올리지 않는다.
시세 지연·기준일 불일치가 있으면 새로운 데이터 배포는 차단하고 웹 코드만 기존 데이터 유지 방식으로 배포한다.
웹 코드만 배포한 공개 화면에는 새 로컬 AI 분석이 자동으로 전달되지 않는다. 데이터 검사를 통과한 스냅샷 갱신이 별도로 필요하다.
