## 변경 내용

1. 기존 `window_end_p50`를 카드의 주 지표인 **관찰기간 말 수익 · 중앙값**으로 표시한다.
   비용 전 과거 관찰값이며, 학습에 사용한 표본을 다시 요약한 것이다. 실제 다음 날 시가 체결 성과나 독립 검증 수익이 아니다.
2. 기존 사후 최고가 통계는 **과거 피크 상승폭 · 중앙값**으로 구분한다.
   연도별 최고 상승폭의 중앙값이고, 그 최고가에 매도할 수 있었다는 뜻이 아니다.
3. 같은 관찰기간 말에 수익이 양수였던 횟수를 `n/N회 상승`으로 보여준다.
   월간 승률·피크 상승 비율을 이 기간의 전략 승률처럼 섞어 보여주지 않는다.
4. 전체 관찰기간의 기준 종가 대비 저가 하락과, 종가 누적 고점 대비 최대낙폭을 별도로 계산한다.
   기준일 저가는 종가 기준 이전의 값이므로 새 하락 계산에서 제외한다.
   원시 저가 자료가 없으면 저가 하락을 0%로 만들지 않고 산출 불가로 유지한다.
5. 실제 체결 검증이 없으므로 `strategy_net_return_p50=null`, `EXECUTION_NOT_VALIDATED`를 명시한다.
6. TOP3·시즌 카드·상세에서 동일한 표시 함수를 사용한다. 축약 API에도 새 지표와 검증 상태를 전달한다.
7. 시즌 퍼센트는 소수 비율이라는 단위를 고정했다. null은 0%가 아닌 대시, 3.0은 3%가 아닌 300%다.
8. 피크 계산 캐시 버전을 2→3으로 올려 같은 날짜의 이전 계산 캐시를 재사용하지 않는다.
   시즌 스냅샷은 기존 소스 코드 해시 변경 감지에 의해 갱신 대상으로 구분된다.

## 후속 작업: 1-B 체결 진단 기반 (2026-09-08)

일반 전략 엔진과 운영 카드의 선정·점수·수익 데이터는 바꾸지 않았다.

- 종가 신호일 다음 제공 거래일부터 시가 진입, 사전 선택 청산일의 시가 청산.
- 시가 누락은 종가로 대체하지 않는다. 최대 대기 횟수는 제공 거래일 기준으로 첫 시도를 포함한다.
- 매수는 청산 예정일 전에만 허용한다. 진입·청산 실패 및 보유 중 자료 누락은 순수익 null과 사유로 보존한다.
- 유동성은 직전 최대 20거래일의 종가×거래량 평균이다. 충분하지 않은 기간은 확보된 직전 거래일만 사용하며,
  그 구간의 자료가 누락되면 미체결 처리한다. 당일 총거래량으로 시장참여율을 정하지 않는다.
- 거래량 0 검사는 **사후 무거래 확인**이며, 장 시작 전 정보라고 주장하지 않는다.
- 상·하한가 부근 시가에는 방향별 보수적인 미체결 대용 규칙을 사용한다. 실제 호가 체결 재현이 아니다.
- 기존 `ExecutionModel`의 비용·날짜별 세율 구조를 재사용한다. 새 실제 세율은 가정하지 않았다.
  테스트의 세율과 수수료는 합성 사례다. 정책과 해시를 결과에 함께 남긴다.
- 순수익 = (청산 시가 / 진입 시가) × (1−매도 비용률) / (1+매수 비용률) − 1.
  소수 수량·비용률 가정이며 최소 주문수량, 호가단위, 실제 원 단위 세금 반올림은 미반영이다.
- 기존 종가 기반 원시 진단과 새 시가 기반 체결 진단을 같은 수익으로 합치지 않는다.
  연도별 결과 `execution_diagnostic`에 별도 저장하며 검증 완료 건수는 계속 0이다.

검증: 기존 59개와 새 체결/연결 회귀 12개를 합친 **71개 통과**.
