# 남은 과제와 최종 재검증 — 2026-09-08

## 결론

현재 로컬 입력으로 실행할 수 있는 코드·데이터·메뉴 연동 검증을 수행하고, 추가로 발견한 수급 오류 경로를 보완했다. **전체 전략의 수익성·생존편향·과거 원천 완비까지 검증된 것은 아니다.** 코드 테스트 통과와 투자 성과 검증을 분리한다. 모바일 개선이나 점수 배점 변경은 하지 않았다.

## 이번에 추가로 고친 사항

1. 공식 수급에서 순매수 금액이 없는 행을 주식 수량이나 0으로 바꾸어 누적하던 경로를 현재 신호에서 차단했다. 금액은 유한한 원화 값만 허용하고 bool/NaN/inf/중복 날짜를 거절한다. 누락 날짜를 지워 연속 매수처럼 이어 붙이지 않도록 해당 투자자 시계열 전체를 제공된 조회 범위에서 제외한다.
2. 공식 수급 상세의 현재 누적값은 원본 차트가 아니라 위 검사를 통과한 행으로 계산한다. 날짜마다 기금과 기관합계를 번갈아 더하지 않고 한 주체만 사용한다. 응답에 KRW 단위와 누적 주체를 명시했다. 원본 이력은 보존했다.
3. 토스 외국인·기관 원본 누락과 명시적인 0을 구분하는 `source_complete`를 요약 전에 판정한다. 누락/비수치 원본은 현재 후보에서 제외한다. 기존 표시용 숫자 변환 자체를 모두 바꾼 것이 아니라, 필수 원본이 없는 요약을 현재 신호로 사용하지 않는 조치다.
4. 시즌 피크 캐시 회귀검사의 임시 설정에 거래상태 경로가 빠진 테스트 오류를 수정하고, 거래상태 파일이 바뀌면 캐시를 무효화하는 검사를 추가했다.

근거: `output/audit/flow-edge-cases-20260908.json`, `output/audit/flow-edge-cases-fixed-20260908.json`. SHA-256 봉투로 저장. `scripts/audit_flow_edge_cases.py`는 합성 입력과 읽기 전용 DB 조회만 사용하며 수집·주문·배포하지 않는다.
