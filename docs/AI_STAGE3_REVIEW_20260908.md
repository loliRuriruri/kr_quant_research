# AI 도입 3단계 검증 — 2026-09-08

## 결론

표시·계약 방어는 반영했다. 실제 무료 모델의 분석 품질 승인은 보류한다.
현재 시즌 브리핑을 직접 호출했으나 Nvidia 상위 공급자 과부하(HTTP 502)로 실패했다.
단회 전체 소요 43.41초(원본 준비 + API 호출 포함). 모델만의 지연 또는 평균 지연이 아니다.
응답은 UNAVAILABLE / ai_generated=false / cache.stored=false였고 유료 전환은 없었다.
모델이 생성한 성공 출력이 없어 수치 정확성·인과관계·표현 품질을 통과했다고 주장할 수 없다.

## 적용

- 공통 메뉴 브리핑 및 종목 뉴스/공시/기술·수급 해석: 실제 ai_generated=true인 경우 작은 AI 배지. 생성 상태와 모순되면 표시하지 않는다.
- 규칙 대체·자료 부족·실패 응답에는 AI 배지 없음. 캐시 재사용은 실제 생성 여부를 그대로 따른다.
- 신규 심층 텍스트 리포트는 생성 출처 플래그를 저장하고 본문에 배지 표시. 과거 플래그 없는 리포트는 임의로 AI 생성으로 추정하지 않는다. 인포그래픽 자체 및 간단 리서치의 출처 표시는 후속 점검 대상.
- 시즌 카드의 결론/근거/주의점/다음 확인 및 가설 배열 형식·길이·NaN/Inf를 검증. 잘못된 생성은 정상 캐시에 저장하지 않는다. 과거 캐시도 검사한다.
- 모델 payload가 AI 생성 여부·제공자·퀀트 점수 반영 여부 등 서버 출처 메타데이터를 덮어쓰지 못하게 변경.
- 원본 수치·종목 순위·기존 상세 정보는 삭제하거나 AI로 재계산하지 않았다.

## 검증 및 한계

Python 계약/시즌 카드/비용 경계/메뉴 근거 24개 통과. JS 배지/대체 응답/중복 표시/시즌 카드 3개 통과.
이는 자동 테스트 결과이지 실제 AI의 사실 정확성 평가가 아니다. 구조 검증은 허위 수치나 근거 없는 인과 설명을 완전히 탐지하지 못한다.
브라우저 시각 검증과 공개 배포는 이번 범위에서 하지 않았다.

## 남은 3단계 품질 승인 조건

공급자 정상화 후 무료 경로로 정상·약세·소표본·현재 근거 누락·오래된 기준일 5개 입력을 평가한다.
각 입력/출력/소요 시간/실패를 보존하고 다음을 직접 대조한다:

1. 종목·기준일·수익률 단위·부호가 원본과 일치하는가?
2. 과거 관측을 올해의 예측·실제 체결 수익으로 말하지 않는가?
3. 누락 수급/뉴스를 만들어내거나 0·호재로 간주하지 않는가?
4. 반대 근거와 구체적인 다음 확인을 짧게 제시하는가?
5. 공급자 실패 시 원본 UI가 유지되고 유료로 자동 전환하지 않는가?

성공 출력 검토 전 다른 메뉴로 분석 기능을 확대하지 않는다. 자동 재시도/유료 호출은 실행하지 않았다.
