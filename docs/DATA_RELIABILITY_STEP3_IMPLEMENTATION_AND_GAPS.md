## 적용한 보완

1. PIT 검사에서 이용 가능일 열이 없거나 날짜가 누락/잘못됐으면 통과시키지 않도록 변경.
2. 실제 시즌 패턴 생성에 명시적 기준일 전달. 종료되지 않은 달과 미래 연도, 날짜가 없는 과거 통계를 현재 선정에 섞지 않는 기존 엄격 경로를 운영에 연결.
3. 기간 분리 진단에서 월초 시가와 전월 마지막 종가 간35% 초과 점프도 검사. 월별로 나눈 뒤 불연속이 사라지는 오류를 차단. 이상 구간을 제외하되 전체 검증 연도 분모와 제외 사유 보존.
4. 공식 기업행위 보정에 관측 범위 이후 사건을 사용하지 않음. 가격 입력 순서가 뒤집혀도 수익률은 시간 순서로 계산하고 반환 행 순서는 유지.
5. 유상 권리락/감자를 단순 주식수 비율로 분할 보정하던 경로 차단. 청약가격·현금조건 없이 올바른 경제적 수익률을 계산할 수 없으므로, 조건 없는 사건은 자동 보정/설명 근거로 사용하지 않음. 실제 원천 파일 부재를 채웠다는 의미는 아님.
6. 계절성 연도별 상승 비율의 Wilson95 구간, 단측 이항검정 참고 p값, 전체 종목×12개월 기준 Bonferroni 참고 보정 제공. 승률 필터를 통과한 승자 수만 보정 분모로 쓰지 않음. 이번 실제 가족크기29,664조합, 통계가 붙은3756패턴.
7. 상세 PC 패널에 표본·구간·보정값·미검증 사유 표시. 연도 분리 패널도 미관측/제외 연도와 불확실성 표시. Quant 점수/순위를 통계값으로 임의 재가중하지 않음.

## 통계 해석 제한

3개년 모두 상승해도 관측 상승률100%의 Wilson95 참고 구간은 약43.85%~100%다. 다음 거래의 성공확률이 아니고, 연도 독립이라는 가정을 확인한 것도 아니다. 이항검정은 상승확률50%라는 기준가정이지 시장 초과수익 검정이 아니다. 보정 범위는 현재 한 번의 월×종목 탐색이며 여러 기간/전략/반복 설계의 전체 탐색 이력까지 보정하지 않았다. 따라서 통계값이 좋아도 `verified=false`를 유지한다.

방법 참고: [NIST Wilson 구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm), [R 공식 다중검정 보정 문서](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html). 참고 통계이지 미검증 원천을 검증된 것으로 바꾸는 도구가 아니다.
